# ไฟอัตโนมัติ KidBright v1.3

ระบบไฟส่องสว่างในโรงเรียนที่เปิดเองเมื่อฟ้ามืด และดับเองเมื่อฟ้าสว่าง โดยใช้บอร์ด **KidBright v1.3** เพียงตัวเดียว **ไม่ต่อสายเพิ่มเติมใด ๆ**

- เซนเซอร์วัดแสง: LDR บนบอร์ด (analog, **GPIO36**)
- ตัวแทน "หลอดไฟ": จอ LED Matrix 16×8 บนบอร์ด (HT16K33, I2C address **0x70**)
- ปุ่มบังคับเปิด/ปิด: **S1 = GPIO16** (บังคับเปิด), **S2 = GPIO14** (บังคับปิด), กดค้างพร้อมกัน = กลับอัตโนมัติ
- บอร์ดที่ใช้: KidBright v1.3 / ชิป ESP32-D0WDQ6 (ตรวจพบที่พอร์ต COM4)

เว็บสาธิต/คู่มือฉบับเต็ม (มีจำลองการทำงานแบบอินเตอร์แอกทีฟ): https://claude.ai/artifact/QDQDa79f34YzBSg2XCSnSm

> พิน S1/S2 และค่าคาลิเบรตเซนเซอร์แสงด้านล่าง **วัดจริงจากบอร์ดตัวนี้** (ไม่ใช่ค่าจากคู่มือทั่วไป) เพราะของจริงมักคลาดเคลื่อนจากสเปกกลาง

## สถานะ: อัปโหลดโค้ดจริงลงบอร์ดแล้ว ✅

เขียนเป็น Arduino C++ (ไม่ใช่บล็อก KidBright IDE) แล้วอัปโหลดผ่าน Arduino IDE (arduino-cli) ไปยังบอร์ดที่ COM4 เรียบร้อย ไฟล์อยู่ที่ [`kidbright_autolight.ino`](kidbright_autolight.ino)

**ทดสอบจริงแล้วและแก้ไข 2 รอบ:**
1. ค่าคาลิเบรตเซนเซอร์ตัวอย่างทั่วไป (raw 0–400) ผิดกับบอร์ดนี้ ทำให้ไฟติดค้างตลอดเวลา → วัดค่าจริงใหม่ (ห้องปกติ raw ~430–510, บังมือมืดสนิท raw ~590–745 — **ค่า raw ยิ่งมากยิ่งมืด**) แล้วคาลิเบรตใหม่
2. ไฟกระพริบตอนแสงอยู่ใกล้เกณฑ์ → เพิ่ม hysteresis (เปิดที่ค่า < 45, ปิดที่ค่า > 60), smoothing, และห้ามสลับสถานะถี่กว่า 2 วินาที

## หลักการทำงาน (ในโค้ด Arduino)

1. อ่านค่าดิบจาก LDR (GPIO36) ทุก 50ms แล้วแปลงเป็นค่าความสว่าง 0–100 ด้วยค่าคาลิเบรตจริงของบอร์ดนี้ (0 = มืดสนิท, 100 = สว่างที่สุด)
2. โหมดอัตโนมัติ: มืดกว่า 45 → เปิดไฟ, สว่างกว่า 60 → ปิดไฟ (ช่วง 45–60 เป็นโซนกันกระพริบ)
3. ปุ่ม S1/S2 บังคับโหมดเปิด/ปิดได้ตลอดเวลา โดยไม่สนใจค่าจากเซนเซอร์ กดค้างพร้อมกัน 0.8 วินาทีเพื่อกลับโหมดอัตโนมัติ
4. เปิด/ปิดจอ LED Matrix (fill ทั้งหมด / clear) แทนการเปิด-ปิดหลอดไฟจริง

ปรับความไวได้ที่ค่า `DARK_ON_THRESHOLD` / `DARK_OFF_THRESHOLD` ในไฟล์ `.ino`

## คำสั่งอัปโหลดซ้ำ (ถ้าต้องแก้โค้ดภายหลัง)

ใช้ arduino-cli ที่มากับ Arduino IDE ที่ติดตั้งไว้แล้วในเครื่องนี้:

```
ARDCLI="C:\Users\TnW_COM4\AppData\Local\Programs\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe"
"$ARDCLI" compile --fqbn esp32:esp32:esp32 kidbright_autolight
"$ARDCLI" upload -p COM4 --fqbn esp32:esp32:esp32 kidbright_autolight
```

ไลบรารีที่ต้องมี (ติดตั้งไว้แล้ว): Adafruit GFX Library, Adafruit LED Backpack Library

## แผนขั้นถัดไป (ยังไม่ได้ทำ): เปิด–ปิดจากมือถือ + ประวัติย้อนหลังผ่าน NETPIE

บอร์ดมี WiFi ในตัว (ESP32) จึงต่อกับแพลตฟอร์มฟรี **NETPIE** (ของ NECTEC หน่วยงานเดียวกับ KidBright) เพื่อบังคับเปิด/ปิดจากแอปและเก็บประวัติพร้อมเวลาได้ โดยไม่ต้องต่อฮาร์ดแวร์เพิ่ม — ส่วนนี้ต้องรอผู้ใช้ทำเอง 2 ขั้น เพราะเป็นบัญชี/รหัสผ่านที่ผู้ช่วย AI กรอกแทนไม่ได้:

1. สมัครบัญชี NETPIE ฟรีที่ netpie.io แล้วสร้าง Device ใหม่แบบ Freeboard เพื่อได้ Device ID / Key / Secret
2. เพิ่มไลบรารี NETPIE/PubSubClient ในโค้ด ใส่ WiFi SSID/รหัสผ่าน + Device ID/Key/Secret แล้ว publish ค่าความสว่าง+สถานะไฟขึ้น NETPIE Feed ทุกครั้งที่เปลี่ยน — NETPIE เก็บประวัติพร้อมเวลาให้อัตโนมัติ และ Freeboard ใช้ทำสวิตช์เปิด/ปิดระยะไกลได้

> เว็บสาธิตมีโหมด "อัตโนมัติ / บังคับเปิด / บังคับปิด" และแผงประวัติย้อนหลังจำลองไว้ให้ดูตัวอย่างพฤติกรรมที่ตั้งใจไว้ก่อนต่อ NETPIE จริง

## เวอร์ชันบล็อก (KidBright IDE) — ทางเลือกเดิม

ถ้าอยากเขียนด้วยบล็อกลาก-วางแทน Arduino C++ ใช้ตรรกะเดียวกัน:

| ลำดับ | บล็อก | หมวด |
|---|---|---|
| 1 | Forever | Control |
| 2 | if...else | Logic |
| 3 | Light level sensor < 45 | Sensor + Math |
| 4 | (จริง) LED Matrix fill ทั้งหมด | Display |
| 5 | (เท็จ) LED Matrix clear | Display |
| 6 | wait 0.5 วินาที | Control |
