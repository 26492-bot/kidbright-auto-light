# ไฟอัตโนมัติ KidBright v1.3

ระบบไฟส่องสว่างในโรงเรียนที่เปิดเองเมื่อฟ้ามืด และดับเองเมื่อฟ้าสว่าง โดยใช้บอร์ด **KidBright v1.3** เพียงตัวเดียว **ไม่ต่อสายเพิ่มเติมใด ๆ**

- เซนเซอร์วัดแสง: LDR บนบอร์ด (analog, GPIO36)
- ตัวแทน "หลอดไฟ": จอ LED Matrix 16×8 บนบอร์ด (ติด = ไฟเปิด, ดับ = ไฟปิด)
- บอร์ดที่ใช้: KidBright v1.3 (ตรวจพบที่พอร์ต COM4)

เว็บสาธิต/คู่มือฉบับเต็ม (มีจำลองการทำงานแบบอินเตอร์แอกทีฟ): https://claude.ai/artifact/QDQDa79f34YzBSg2XCSnSm

## หลักการทำงาน

1. อ่านค่าความสว่างจาก Light level sensor (LDR) ได้ค่า 0–100 (0 = มืดสนิท, 100 = สว่างที่สุด)
2. เปรียบเทียบค่ากับเกณฑ์ (threshold) เช่น 35 — ถ้าค่าที่อ่านได้ **น้อยกว่า** เกณฑ์ ถือว่ามืดแล้ว
3. มืด → สั่งจอ LED Matrix แสดงผลติดทั้งหมด (เปิดไฟ) / สว่าง → สั่งดับจอ LED Matrix (ปิดไฟ)
4. วนซ้ำทุก 0.5 วินาทีในบล็อก Forever

## บล็อกใน KidBright IDE

| ลำดับ | บล็อก | หมวด |
|---|---|---|
| 1 | Forever | Control |
| 2 | if...else | Logic |
| 3 | Light level sensor < 35 | Sensor + Math |
| 4 | (จริง) LED Matrix fill ทั้งหมด | Display |
| 5 | (เท็จ) LED Matrix clear | Display |
| 6 | wait 0.5 วินาที | Control |

ปรับตัวเลข `35` ในเงื่อนไขข้อ 3 เพื่อเพิ่ม/ลดความไวของเซนเซอร์ตามสภาพแสงจริงของโรงเรียน

## วิธีอัปโหลดลงบอร์ด

1. เปิดโปรแกรม **KidBright IDE** (ดาวน์โหลดฟรีที่ kid-bright.org หากยังไม่มี)
2. ตั้งค่าบอร์ดเป็น **KidBright v1.3**
3. เลือกพอร์ต **COM4**
4. ลากบล็อกตามตารางด้านบน แล้วกด **Upload**
