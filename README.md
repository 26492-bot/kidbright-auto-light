# ไฟอัตโนมัติ KidBright v1.3

ระบบไฟส่องสว่างในโรงเรียนที่เปิดเองเมื่อฟ้ามืด และดับเองเมื่อฟ้าสว่าง โดยใช้บอร์ด **KidBright v1.3** เพียงตัวเดียว **ไม่ต่อสายเพิ่มเติมใด ๆ** ควบคุมเปิด/ปิดเองได้ทั้งจากปุ่มบนบอร์ดและจากเว็บแบบเรียลไทม์

- เซนเซอร์วัดแสง: LDR บนบอร์ด (analog, **GPIO36**)
- ตัวแทน "หลอดไฟ": จอ LED Matrix 16×8 บนบอร์ด (HT16K33, I2C address **0x70**)
- ปุ่มบังคับเปิด/ปิด: **S1 = GPIO16** (บังคับเปิด), **S2 = GPIO14** (บังคับปิด), กดค้างพร้อมกัน = กลับอัตโนมัติ
- WiFi: **TNW-WIFI2** (เน็ตเปิด ไม่มีรหัส) — ใช้ WiFi ในตัวชิป ESP32 ไม่ต้องต่อฮาร์ดแวร์เพิ่ม
- บอร์ดที่ใช้: KidBright v1.3 / ชิป ESP32-D0WDQ6 (ตรวจพบที่พอร์ต COM4)

เว็บควบคุม/คู่มือฉบับเต็ม: https://claude.ai/artifact/QDQDa79f34YzBSg2XCSnSm (หรือ https://26492-bot.github.io/kidbright-auto-light/)

> พิน S1/S2 และค่าคาลิเบรตเซนเซอร์แสงด้านล่าง **วัดจริงจากบอร์ดตัวนี้** (ไม่ใช่ค่าจากคู่มือทั่วไป) เพราะของจริงมักคลาดเคลื่อนจากสเปกกลาง

## สถานะ: ใช้งานได้จริงครบทั้งบอร์ดและเว็บ ✅

เขียนเป็น Arduino C++ อัปโหลดผ่าน Arduino IDE (arduino-cli) ไปยังบอร์ดที่ COM4 ไฟล์อยู่ที่ [`kidbright_autolight/kidbright_autolight.ino`](kidbright_autolight/kidbright_autolight.ino)

**ทดสอบจริงบนฮาร์ดแวร์และแก้บั๊กที่เจอระหว่างทาง:**
1. ค่าคาลิเบรตเซนเซอร์ตัวอย่างทั่วไปผิดกับบอร์ดนี้ → ไฟติดค้างตลอดเวลา → วัดค่าจริงใหม่ (ห้องปกติ raw ~430–510, บังมือมืดสนิท raw ~590–745 — **ค่า raw ยิ่งมากยิ่งมืด**) แล้วคาลิเบรตใหม่
2. ไฟกระพริบตอนแสงอยู่ใกล้เกณฑ์ → เพิ่ม hysteresis, smoothing, และห้ามสลับสถานะถี่กว่า 2 วินาที
3. แก้ threshold ให้ไวขึ้นตามที่ทดสอบจริง แต่ตั้งค่ากลับด้าน (on > off) ทำให้กระพริบอีกรอบ → แก้ให้ on < off เสมอ
4. `WiFi.begin(ssid, "")` กับเน็ตเปิดไม่มีรหัสทำให้บอร์ดค้าง/รีเซ็ตเงียบๆ → ต้องเรียก `WiFi.begin(ssid)` เฉยๆ เมื่อไม่มีรหัสผ่าน
5. เจอ brownout reset หนึ่งครั้งระหว่างทดสอบ (ไฟกระชากตอน WiFi ทำงาน) — บอร์ดรีเซ็ตแล้วทำงานต่อได้เอง ถ้าเจอบ่อยลองเปลี่ยนสาย/พอร์ต USB
6. ntfy.sh (ตัวกลางเชื่อมเว็บกับบอร์ด) จำกัด ~1 คำขอ/5 วิ และ 250 ข้อความ/วันต่อ IP → ลดความถี่ซิงก์จาก 3 วิ เหลือ 20 วิ
7. ทดสอบซ้ำถี่ๆ (ทั้งจากบอร์ดและเว็บพร้อมกัน) ยังชน rate limit ได้อยู่ ทำให้คำสั่งเงียบหายไปเฉยๆ (fetch ล้มเหลวแบบไม่มี error โชว์) → ยืดรอบซิงก์อีกครั้งเป็นบอร์ด 30 วิ / เว็บ 25 วิ ถ้ากดปุ่มแล้วยังไม่ติด ให้รอสัก 1-2 นาทีแล้วลองใหม่ (ให้โควตาฟื้นตัว) ก่อนสงสัยว่าโค้ดพัง

## หลักการทำงาน (ในโค้ด Arduino)

1. อ่านค่าดิบจาก LDR (GPIO36) ทุก 50ms แล้วแปลงเป็นค่าความสว่าง 0–100 ด้วยค่าคาลิเบรตจริงของบอร์ดนี้ (0 = มืดสนิท, 100 = สว่างที่สุด)
2. โหมดอัตโนมัติ: มืดกว่า 55 → เปิดไฟ, สว่างกว่า 70 → ปิดไฟ (ช่วง 55–70 เป็นโซนกันกระพริบ)
3. ปุ่ม S1/S2 บนบอร์ด **หรือ** ปุ่มบนเว็บ บังคับโหมดเปิด/ปิดได้ตลอดเวลา โดยไม่สนใจค่าจากเซนเซอร์ กดปุ่มบนบอร์ดพร้อมกัน 0.8 วินาทีเพื่อกลับโหมดอัตโนมัติ
4. เปิด/ปิดจอ LED Matrix (fill ทั้งหมด / clear) แทนการเปิด-ปิดหลอดไฟจริง
5. ทุก 30 วินาที: ต่อ WiFi (ถ้ายังไม่ต่อ) → ดึงคำสั่งล่าสุดจากเว็บ → ส่งค่าความสว่าง/สถานะไฟ/โหมดปัจจุบันกลับไปให้เว็บแสดง

ปรับความไวได้ที่ค่า `DARK_ON_THRESHOLD` / `DARK_OFF_THRESHOLD` ในไฟล์ `.ino` (ต้องให้ ON น้อยกว่า OFF เสมอ ไม่งั้นไฟจะกระพริบ)

## เว็บเชื่อมกับบอร์ดจริงได้อย่างไร

บอร์ดกับเว็บไม่ได้คุยกันตรงๆ (คนละเครือข่าย/HTTPS ไม่รองรับ) จึงผ่านตัวกลางฟรีที่ไม่ต้องสมัครสมาชิก **[ntfy.sh](https://ntfy.sh)**:

- เว็บกดปุ่มโหมด → ส่งข้อความ `on`/`off`/`auto` ไปยัง topic `kidbright-cmd-Gs19S5zFML4da5fiUmsi8p`
- บอร์ด poll topic นี้ทุก 30 วิ แล้วตั้งโหมดตามคำสั่งล่าสุด
- บอร์ด POST สถานะปัจจุบัน (`{light, lamp, mode}`) ไปยัง topic `kidbright-status-Gs19S5zFML4da5fiUmsi8p` ทุก 30 วิ
- เว็บ poll topic สถานะทุก 25 วิ มาแสดงเป็นการ์ด "ควบคุมบอร์ดจริง"

Topic ทั้งสองเป็นชื่อสุ่มไม่ซ้ำใคร (ไม่ใช่ระบบส่วนตัวจริง ใครรู้ชื่อ topic ก็ส่ง/อ่านได้ — เหมาะกับโปรเจกต์โรงเรียน ไม่เหมาะกับของที่ต้องปลอดภัยสูง) คำสั่งจะไปถึงบอร์ดภายใน ~30 วินาที บอร์ดต้องเปิดเครื่องและต่อ WiFi TNW-WIFI2 อยู่จึงจะเห็นผล

## คำสั่งอัปโหลดซ้ำ (ถ้าต้องแก้โค้ดภายหลัง)

ใช้ arduino-cli ที่มากับ Arduino IDE ที่ติดตั้งไว้แล้วในเครื่องนี้:

```
ARDCLI="C:\Users\TnW_COM4\AppData\Local\Programs\Arduino IDE\resources\app\lib\backend\resources\arduino-cli.exe"
"$ARDCLI" compile --fqbn esp32:esp32:esp32 kidbright_autolight
"$ARDCLI" upload -p COM4 --fqbn esp32:esp32:esp32 kidbright_autolight
```

ไลบรารีที่ต้องมี (ติดตั้งไว้แล้ว): Adafruit GFX Library, Adafruit LED Backpack Library

## เวอร์ชันบล็อก (KidBright IDE) — ทางเลือกเดิม

ถ้าอยากเขียนด้วยบล็อกลาก-วางแทน Arduino C++ ใช้ตรรกะพื้นฐานเดียวกัน (ไม่รวมส่วนเชื่อมเว็บ):

| ลำดับ | บล็อก | หมวด |
|---|---|---|
| 1 | Forever | Control |
| 2 | if...else | Logic |
| 3 | Light level sensor < 55 | Sensor + Math |
| 4 | (จริง) LED Matrix fill ทั้งหมด | Display |
| 5 | (เท็จ) LED Matrix clear | Display |
| 6 | wait 0.5 วินาที | Control |
