โค้ดที่ใช้งานจริงบนบอร์ด

เขียนเป็น Arduino C++ อัปโหลดผ่าน Arduino IDE (arduino-cli) — ไม่ใช่บล็อกลาก-วาง

  1. 1
    วนซ้ำตลอดเวลาใน loop()อ่านเซนเซอร์ + เช็คปุ่ม + ซิงก์เว็บ ทุก 50 มิลลิวินาที
  2. 2
    เทียบค่าแสงกับเกณฑ์ (มี hysteresis กันกระพริบ)มืดกว่า 55 → เปิด, สว่างกว่า 70 → ปิด
  3. 3
    ฝั่ง "เปิด": matrix.fillScreen(LED_ON)จุดจอ LED 16×8 ทั้งหมด
  4. 4
    ฝั่ง "ปิด": matrix.clear()ดับจอ LED ทั้งหมด
  5. 5
    ปุ่ม S1/S2 หรือปุ่มบนเว็บบังคับโหมดได้ตลอดไม่สนใจค่าเซนเซอร์เมื่ออยู่โหมดเปิด/ปิดค้าง

คำสั่งอัปโหลดซ้ำ (ต้องมี Arduino IDE + ESP32 core ติดตั้งไว้):

arduino-cli compile --fqbn esp32:esp32:esp32 kidbright_autolight
arduino-cli upload -p COM4 --fqbn esp32:esp32:esp32 kidbright_autolight

เชื่อม WiFi ง่ายๆ ไม่ต้องแก้โค้ด

บอร์ดใช้ชิป ESP32 ที่มี WiFi ในตัว ลองต่อเน็ตที่รู้จักอยู่แล้วก่อนอัตโนมัติ ถ้าไม่เจอ (เช่นย้ายไปที่อื่น) จะเปิดฮอตสปอตของตัวเองให้ตั้งค่าเน็ตใหม่ได้ทันทีโดยไม่ต้องเขียนโค้ดหรืออัปโหลดซ้ำ

  1. 1
    เปิดบอร์ดลองต่อ WiFi TNW-WIFI2 อัตโนมัติภายใน 8 วินาที
  2. 2
    ถ้าต่อไม่ได้ บอร์ดจะปล่อยฮอตสปอตชื่อ "KidBright-Setup"เอามือถือ/คอมไปเชื่อมต่อ WiFi นี้
  3. 3
    หน้าตั้งค่าจะเด้งขึ้นเองเลือกชื่อ WiFi จริงที่ต้องการ ใส่รหัสผ่าน แล้วกดบันทึก
  4. 4
    บอร์ดต่อเน็ตใหม่และจำไว้ครั้งต่อไปจะต่อเน็ตนี้เองอัตโนมัติ ไม่ต้องตั้งซ้ำ
💡
ไม่มี WiFi ก็ยังใช้ได้ ระบบไฟอัตโนมัติและปุ่ม S1/S2 บนบอร์ดทำงานได้เองเสมอ ไม่ต้องพึ่งอินเทอร์เน็ต — WiFi จำเป็นเฉพาะฟีเจอร์ควบคุม/ดูสถานะผ่านเว็บเท่านั้น

เว็บคุยกับบอร์ดจริงได้อย่างไร

บอร์ดกับเว็บอยู่คนละเครือข่ายกัน จึงผ่านตัวกลางฟรีไม่ต้องสมัครสมาชิก ntfy.sh

  1. 1
    กดปุ่มบนเว็บส่งข้อความ on / off / auto ไปยัง topic คำสั่งเฉพาะของโปรเจกต์นี้
  2. 2
    บอร์ด poll คำสั่งทุก 30 วินาทีแล้วตั้งโหมดตามคำสั่งล่าสุดที่ได้รับ
  3. 3
    บอร์ดส่งสถานะกลับทุก 30 วินาทีค่าความสว่าง สถานะไฟ และโหมดปัจจุบัน
  4. 4
    เว็บ poll สถานะทุก 25 วินาทีมาแสดงในการ์ดด้านบน — คำสั่งถึงบอร์ดภายใน ~30 วินาที
⚠️
บริการฟรีนี้จำกัดความถี่ค่อนข้างเข้ม ถ้ากดปุ่มรัวๆ หรือมีคนใช้พร้อมกันหลายคนในเครือข่ายเดียวกัน อาจโดนจำกัดชั่วคราวจนคำสั่งไปไม่ถึง (ไม่มี error โชว์ให้เห็น) รอสัก 1-2 นาทีแล้วลองใหม่

ปรับความไวของเซนเซอร์

ถ้าไฟติดเร็ว/ช้าเกินไปในสภาพแสงจริงของโรงเรียน แก้ 2 ค่านี้ในไฟล์ .ino แล้วอัปโหลดใหม่

DARK_ON_THRESHOLD  = 55   → มืดกว่านี้ไฟถึงจะติด (ค่ายิ่งสูง ไฟติดง่ายขึ้น)
DARK_OFF_THRESHOLD = 70   → สว่างกว่านี้ไฟถึงจะดับ (ต้อง > ค่า ON เสมอ กันไฟกระพริบ)
