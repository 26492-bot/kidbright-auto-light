ใช้บอร์ด KidBright v1.3 เพียงตัวเดียว ไม่ต่อสายเพิ่มแม้แต่เส้นเดียว — อ่านค่าความสว่างจากเซนเซอร์แสง (LDR) ที่ติดมากับบอร์ด แล้วสั่งจอ LED 16×8 บนบอร์ดทำหน้าที่แทน “หลอดไฟ”

เขียนบล็อกใน KidBright IDE

เปิดโปรแกรม KidBright IDE แล้วลากบล็อกต่อกันตามลำดับนี้ในแท็บ Block

  1. 1
    เริ่มด้วยบล็อก Foreverจากหมวด Control — ทุกอย่างข้างในจะทำงานซ้ำตลอดเวลา
  2. 2
    ใส่บล็อก if…elseจากหมวด Logic วางไว้ในบล็อก Forever
  3. 3
    เงื่อนไข: Light level sensor < 35ลากบล็อก "Light level sensor" จากหมวด Sensor มาเทียบกับตัวเลข (ปรับค่า 35 ได้ตามความไวที่ต้องการ)
  4. 4
    ฝั่ง "จริง": LED Matrix แสดงผล fill (จุดสว่างทั้งหมด)จากหมวด Display — เปรียบเสมือนเปิดไฟ
  5. 5
    ฝั่ง "เท็จ": LED Matrix clear (ดับทั้งหมด)เปรียบเสมือนปิดไฟ
  6. 6
    ปิดท้ายด้วย wait 0.5 วินาทีในบล็อก Forever เพื่อไม่ให้เซนเซอร์อ่านค่าถี่เกินไป

อัปโหลดลงบอร์ด

บอร์ดต่อผ่าน USB อยู่ที่พอร์ต COM4 ในเครื่องนี้แล้ว

  1. 1
    เปิด KidBright IDEดาวน์โหลดได้ฟรีจาก kid-bright.org หากยังไม่มีในเครื่อง
  2. 2
    เลือกรุ่นบอร์ดเป็น KidBright v1.3ในเมนูตั้งค่าบอร์ดมุมขวาบนของโปรแกรม
  3. 3
    เลือกพอร์ต COM4ระบบตรวจพบบอร์ดที่พอร์ตนี้อัตโนมัติ
  4. 4
    กดปุ่ม Uploadรอจนแถบสถานะแจ้งว่าอัปโหลดสำเร็จ ไฟจะเริ่มทำงานทันทีโดยไม่ต้องต่อคอมพิวเตอร์อีก

ปรับความไวของเซนเซอร์

ถ้าไฟติดเร็ว/ช้าเกินไปในสภาพแสงจริงของโรงเรียน ปรับได้ที่ตัวเลขเกณฑ์ในบล็อก if เพียงจุดเดียว

ถ้า Light level sensor < 35   →  เพิ่มตัวเลข = ไฟติดง่ายขึ้น (ไวต่อแสงน้อย)
                              →  ลดตัวเลข   = ไฟติดยากขึ้น (ต้องมืดกว่าเดิม)
